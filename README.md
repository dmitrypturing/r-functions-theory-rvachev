# В. Л. Рвачев. «Теория R-функций и некоторые ее приложения» — конспект изучения

Исходник: `r-functions-theory-rvachev.pdf` (скан, Киев: Наукова думка, 1982, 553 с.).

## Что здесь

| путь | содержание |
|---|---|
| `rvachev-ch1-pp1-29.pdf` | собранный PDF: с. 1–29 книги (предисловие, введение, гл. 1 §§ 1–4) с исправленными опечатками и решениями всех упражнений |
| `tex/` | исходники LaTeX этого PDF |
| `tex/main.tex` | корневой файл; главы — `preface.tex`, `intro.tex`, `ch1-s1.tex` … `ch1-s4.tex` |
| `tex/ch1-s3-solutions.tex`, `tex/ch1-s4-solutions.tex` | решения упражнений §§ 3, 4 (решения §§ 1, 2 — в конце `ch1-s1.tex`, `ch1-s2.tex`) |
| `tex/errata.tex` | приложение: список исправленных опечаток оригинала |
| `notes/claude/` | рабочие заметки из предыдущей беседы (решения упр. 2–7 на с. 21; исследование интегральной формы операции sweeping в FRep и поиск предшествующих работ) |
| `notes/project.json` | метаданные исходного проекта |

## Сборка

```sh
cd tex && make        # pdflatex ×2, результат копируется в ../rvachev-ch1-pp1-29.pdf
```

Нужны пакеты TeX Live: `texlive-latex-recommended texlive-latex-extra texlive-lang-cyrillic texlive-fonts-recommended cm-super`.

## Оформление

* номер страницы оригинала — на полях, `[с. 15]`;
* исправленные опечатки — сноской «Исправлено: …» в месте исправления и сводной таблицей в приложении;
* решения, которых нет в книге, — в синих рамках «Решение упражнения N (§ k)» сразу после блока упражнений;
* рисунки перерисованы в TikZ.
