# В. Л. Рвачев. «Теория R-функций и некоторые ее приложения» — конспект изучения

Исходник: `r-functions-theory-rvachev.pdf` (скан, Киев: Наукова думка, 1982, 553 с.).
Конспект пополняется по мере чтения; сейчас набраны с. 1–29 (предисловие, введение, гл. 1, §§ 1–4).

## Структура

| путь | содержание |
|---|---|
| `rvachev-theory-of-r-functions.pdf` | конспект: текст книги, набранный в LaTeX, с исправленными опечатками |
| `rvachev-exercises.pdf` | решения упражнений (условия + решения по параграфам) |
| `theory/` | исходники конспекта: `main.tex`, `preface.tex`, `intro.tex`, `ch1-s1.tex` … , `errata.tex` (список опечаток), `macros.tex` (общие обозначения) |
| `exercises/` | исходники решений: `main.tex`, `s1.tex` … `s4.tex`, `notes-remarks.tex`; макросы берутся из `../theory/macros.tex` |
| `notes/claude/` | рабочие заметки из предыдущей беседы (упр. на с. 21; интегральная форма sweeping в FRep; поиск предшествующих работ) |
| `notes/project.json` | метаданные исходного проекта |

## Сборка

```sh
cd theory    && make   # -> ../rvachev-theory-of-r-functions.pdf
cd exercises && make   # -> ../rvachev-exercises.pdf
```

Нужны пакеты TeX Live: `texlive-latex-recommended texlive-latex-extra texlive-lang-cyrillic texlive-fonts-recommended cm-super`.

## Соглашения

* формат страницы — как у книги: 60×90/16, т. е. 145 × 215 мм, полоса набора 113 мм (6¼ кв.); в скане страницы меньше (127 × 199 мм), потому что при сканировании обрезаны поля;
* номер страницы оригинала — на полях, `[с. 15]`; нумерация формул, рисунков и упражнений сохранена;
* исправленная опечатка отмечается сноской «Исправлено: …» и вносится в таблицу `theory/errata.tex`;
* рисунки перерисованы в TikZ;
* решения — в синих рамках «Решение упражнения N (§ k)»; собственные решения автора книги остаются в тексте конспекта.

## Как добавить следующий параграф

1. Текст — в новый файл `theory/ch1-s5.tex` (или `ch2-s1.tex`), подключить в `theory/main.tex`.
2. Условия и решения упражнений — в `exercises/s5.tex`, подключить в `exercises/main.tex`.
3. Опечатки — в таблицу `theory/errata.tex`.
