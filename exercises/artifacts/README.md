# Артефакты к решениям упражнений

Вспомогательные материалы к `rvachev-exercises.pdf`, кроме самих `.tex`/`.pdf`.

| файл | что это |
|---|---|
| `code-map-alpha.html` | страница «The Code Map α» из предыдущей сессии: отображение α, сопоставляющее точке универсума ее код в {0,1}³ («уровень 2» в решениях §3). Открывается в браузере. |
| `checks/identities.py` | проверка по таблицам истинности всех тождеств из упражнений §1, §2 и из текста §3 (в том числе того, что напечатанные с опечатками формулы тождествами не являются). |
| `checks/boolean_tables.py` | перебор таблиц истинности для упражнений §3: μ(n), τ(n) (τ(5) = 64 386 — полным перебором), классы при n = 3, четные и уравновешенные формулы, формула F_n из упр. 4. |
| `checks/venn_constructions.py` | численная проверка построений из §2: n выпуклых областей и n параллельных переносов одной области, дающие все 2ⁿ состояний принадлежности. |
| `checks/associativity.py` | численная проверка упражнений §4: операции φ₀…φ₃ вида h⁻¹[h(x)∗h(y)], x|y|, φ_t с обратной функцией через функцию Ламберта, n-местные операции x₁ + ζx₂ + … + ζⁿ⁻¹xₙ. |
| `checks/section5.py` | проверки к §5: схема (1.17) и схемы рис. 12 (и то, что напечатанная формула ((x+2)+3)x+4 дает другой многочлен); подстановка рядов в упр. 2; выражение всех функций (1.9) через H = {x+y, xy, x^y, ln x, sin x, arcsin x} с совпадением областей определения (упр. 4); свидетель xy+z и гасящий множитель для одной структуры на всем ℝⁿ (упр. 5); подсчет производных и лемма о многочленах на примерах (упр. 6). |
| `checks/RESULTS.txt` | вывод всех пяти скриптов. |

Запуск: `python3 checks/<скрипт>.py` (нужен только стандартный Python 3).
