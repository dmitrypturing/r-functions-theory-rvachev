The Code Map α

Level 2: every point of I gets a code

A formula F(A, B, C) never looks at where a point is — only at which of the sets it belongs to. That information is a string of three bits, the point's code. The map that assigns it is α.

Level 1
Sets

Universe I, subsets A, B, C ⊆ I. Points live here.

Level 2 — this picture
Codes

α : I → {0,1}³,  x ↦ (x∈A?, x∈B?, x∈C?).

Level 3
Truth table

f : {0,1}³ → {0,1}, read off the text of the formula.

  • 000outside all three
  • 100only A
  • 010only B
  • 001only C
  • 110A and B, not C
  • 101A and C, not B
  • 011B and C, not A
  • 111in all three

Why the proof chose I = {0,1}³. Normally the left and right pictures are different objects and α is a genuine map between them. If you take the universe to be the cube itself, with A = {codes whose 1st bit is 1}, B = {2nd bit is 1}, C = {3rd bit is 1}, then the two pictures coincide: every region is a single point, and α(x) = x. That is the trick that makes every constituent non-empty — nothing more.
